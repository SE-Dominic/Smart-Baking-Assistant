# Smart-Baking-Assistant

## About the Project

The Smart Kitchen Assistant is an interactive cooking assistant that connects with a smart food scale to make cooking and baking easier and more user-friendly.

Instead of only displaying the weight of an ingredient, the scale and application work together to guide the user through a recipe. The assistant can tell the user when they need to add more of an ingredient, when they have reached the correct amount, or when they have added too much.

## Main Features

- Smart food scale integration
- Live ingredient weight display
- Step-by-step recipe instructions
- Visual feedback for ingredient measurements
- Recipe library
- Adjustable serving and batch sizes
- Generate recipes based on ingredients the user already has
- Text-to-speech instructions

## How It Works

1. The user selects a recipe or enters ingredients they already have.
2. The application guides the user through the recipe step-by-step.
3. The user places their bowl or container on the smart scale.
4. The scale measures the amount of each ingredient added.
5. The assistant tells the user to add more, stop, or correct the amount.
6. The user continues through the recipe until it is complete.

## Future Features

- AI cooking assistant
- Voice interaction
- Ingredient substitutions
- Automatic recipe adjustments when too much of an ingredient is added
- Automatic taring
- Scale-to-website communication

## Goal

Our goal is to create a simple and interactive cooking experience that does more than just measure ingredients.

**A traditional scale tells you the weight. Our Smart Kitchen Assistant tells you what to do with it.**
